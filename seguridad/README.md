# Laboratorio sintético RESTler

[Instrucciones, resultados y límites](../documentacion/actividad/RESTLER.md).

El ejecutor no admite destino externo: crea su API/MySQL/Mailpit nuevos. Requiere un JAR integrado Java21 recién construido, Docker activo y RESTler compilado. `private/` contiene registros y secretos desechables, no se publica. Evidencia pública en documentacion/actividad/evidencia. El análisis se marca incompleto si ResultsAnalyzer falla aunque el proceso principal termine con código 0.
