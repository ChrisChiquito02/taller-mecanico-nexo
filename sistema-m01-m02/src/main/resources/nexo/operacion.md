Plan preparado, NO despliegue verificado: frontend Cloudflare Pages Free, backend contenedor Java 21 en Render Free y MySQL 8.4 autogestionado en Oracle Always Free. Los tres son proveedores distintos. Java llama al modelo por una interfaz sustituible; el modelo 7B no cabe en Render Free. La inferencia pública necesitaría un servicio privado en Oracle con capacidad comprobada; no debe depender de la Mac. No se promete disponibilidad ni latencia de un 7B en CPU ARM gratuita sin medición. Render Free suspende por inactividad y bloquea SMTP 25/465/587: verificar un servicio con STARTTLS en 2525. HTTPS para frontend/API y MySQL VERIFY_IDENTITY con CA válida. Dominios de proveedores diferentes pueden bloquear cookies de terceros; usar subdominios same-site propios o gratuitos aprobados con HTTPS. No usar SameSite=None como garantía universal. No incluir secretos en esbuild ni en el repositorio. Credenciales solo en el entorno del backend y almacenes del proveedor. Verificar cuotas y elegibilidad antes de publicar.
